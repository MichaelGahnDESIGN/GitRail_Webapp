## Warum Eisenbahnen?
Ein Branch ist eine Abzweigung, ein Commit ein dokumentierter Baufortschritt und ein Merge das Zusammenführen von Entwicklungsständen. Das Lernspiel zeigt zusätzlich die Grenzen dieser Bilder.
